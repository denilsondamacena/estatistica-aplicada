3. Biblioteca statistics

Biblioteca padrão ideal para conceitos básicos de Estatística Descritiva.

Função Conceito Estatístico
mean() Média aritmética
median() Mediana
mode() / multimode() Moda / Múltiplas modas
variance() / pvariance() Variância amostral / populacional
stdev() / pstdev() Desvio padrão amostral / populacional
quantiles() Separação por quantis (quartis, decis, etc) 
import statistics as statistics

notas = [5, 6, 7, 7, 8, 9, 10]

print("Média:", statistics.mean(notas))
print("Mediana:", statistics.median(notas))
print("Moda:", statistics.mode(notas))
print("Variância Amostral:", statistics.variance(notas))
print("Desvio Padrão Amostral:", statistics.stdev(notas))

4. Biblioteca NumPy

Essencial para computação numérica, manipulação de vetores, matrizes e álgebra linear.

import numpy as np

notas = np.array([5, 6, 7, 7, 8, 9, 10])

print("Média:", np.mean(notas))
print("Mediana:", np.median(notas))
print("Mínimo / Máximo:", np.min(notas), "/", np.max(notas))

print("Variância Amostral (ddof=1):", np.var(notas, ddof=1))
print("Desvio Padrão Amostral (ddof=1):", np.std(notas, ddof=1))

print("Quartil 50% (Mediana):", np.percentile(notas, 50))

5. Pandas

A ferramenta central para manipulação e análise de dados estruturados em tabelas (DataFrames).

import pandas as pd

dados = {
    "Aluno": ["Ana", "Bruno", "Carlos", "Daniela"],
    "Nota": [8, 7, 9, 6],
    "Faltas": [2, 0, 4, 1]
}

df = pd.DataFrame(dados)

print(df.head(2))
print(df.info())
print(df.describe())

print("Média de notas:", df["Nota"].mean())
print("Frequência de faltas:\n", df["Faltas"].value_counts())

6. Matplotlib

Biblioteca base para visualização gráfica de dados estatísticos.

📊 Manipulação de Gráfico em Tempo Real

Altere a frequência dos dados abaixo e clique em "ATUALIZAR GRÁFICO" para ver o Histograma se modificar:

import matplotlib.pyplot as plt

notas = [5, 6, 6, 7, 7, 7, 8, 8, 9, 10]

plt.figure(figsize=(6, 4))
plt.hist(notas, bins=5, color='purple', edgecolor='yellow')
plt.title("Distribuição das Notas")
plt.xlabel("Nota")
plt.ylabel("Frequência")
plt.grid(True)
plt.show()

plt.boxplot(notas)
plt.title("Boxplot de Notas")
plt.show()
