## `/projeto`

O diretório `/projeto` traz um **Guia Interativo de Estatística Aplicada**, uma aplicação web desenvolvida para transformar conceitos estatísticos em uma experiência dinâmica e visual.

### Principais Recursos:
- **`STAT_CALC.EXE`:** Calculadoras interativas para média, variância, desvio padrão e limites de outliers.
- **Notação Matemática Limpa:** Exibição elegante de equações em LaTeX renderizadas via MathJax.
- **Códigos em Python:** Blocos de código preparados com as bibliotecas **NumPy**, **Pandas** e **Matplotlib**.
- **Integração com Google Colab:** Botões de cópia rápida para execução instantânea na nuvem.
- **Gráficos Interativos:** Visualização de dados dinâmicas utilizando Chart.js.
