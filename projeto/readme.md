## Descrição do Projeto

O **Estatística Aplicada com Python** é um portal educacional interativo criado como guia de estudos para o curso de Análise e Desenvolvimento de Sistemas (ADS).

A proposta do projeto é transformar o aprendizado de conceitos estatísticos e sintaxes em Python em uma experiência imersiva e nostálgica, inspirada nas interfaces da MTV dos anos 90 e em sistemas operacionais retrô (Win95 e MS-DOS). O guia aborda desde comandos essenciais da linguagem até bibliotecas fundamentais como NumPy, Pandas, Matplotlib, Seaborn e SciPy.

Desenvolvido para oferecer praticidade no dia a dia acadêmico, o projeto combina cálculo em tempo real, visualização dinâmica de dados e exportação direta para notebooks do Google Colab.

---

## Funcionalidades

* **Exportador para Google Colab (.ipynb):** Gera e baixa automaticamente um arquivo de notebook Jupyter totalmente estruturado com os códigos exibidos no guia.
* **Manipulação de Gráfico Dinâmico:** Histograma interativo em tempo real via Chart.js, permitindo que o usuário altere as frequências e visualize a modificação imediata da distribuição.
* **Calculadora Estatística Win95 (`STAT_CALC.EXE`):** Componente interativo que processa conjuntos de dados informados pelo usuário, calculando média, mediana e desvio padrão.
* **Terminal Simulado MS-DOS:** Playground para execução e teste rápido de arrays Python.
* **Cópia Rápida de Código:** Botão dedicado em todas as caixas de código para copiar trechos diretamente para a área de transferência.

## Como Executar o Projeto

### Pré-requisitos
Por ser um projeto puramente front-end (client-side), necessita apenas de:

* Um navegador web moderno conectado à internet (necessário para carregar as fontes externas e a biblioteca Chart.js via CDN).

### Passo a Passo para Execução
<ol>
  <li>Realize o clone ou faça o download deste repositório.</li>
  <li>Certifique-se de que as pastas <code>css/</code> e <code>js/</code> estejam no mesmo diretório do arquivo principal.</li>
  <li>Abra o arquivo <code>index.html</code> diretamente em seu navegador.</li>
</ol>
